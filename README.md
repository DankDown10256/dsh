# DSH (DevShell)

Dsh is a shell that want to help developers to have a smoother workflow when they need their terminal by adding features by default so you don't have to lose time in config files.

## Features

- Git repo detection and branch displayed.
- Python venv handling (acpyvenv, deactivate)
- Command timing when it takes more than 5 seconds
- Pipelines support with runwith command
- History

## Installation

```bash
sudo make install
```
## Uninstallation

```bash
sudo make uninstall
```

## Usage 

Just run the following command:

```bash
dsh
```
And the shell will be launched
