# Contributing

First I want to thank you for being interested in contributing to make dsh better.

## How to contribute

To contribute just fork the repo clone your forked repository.

Create a branch with the fix or feat name:

```bash
git checkout -b fix-fix_name
```
Or:
```bash
git checkout -b feat-feat_name
```
Then push you changes for the branch and open a pr a maintainer will review it as soon as possible.

Note:
In the pull request explication note (not in the commit message) try to explain what you fixed exactly and why and for a feat try to explain why your feature does that.
